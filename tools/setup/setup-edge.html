4 Test Password Reset in Edge
  1. Click the PasteCraft icon in Edge toolbar
  2. Click "Forgot Password?"
  3. Enter your email and click "Send Reset Link"
  4. Check your Gmail for the reset email
  5. Click the reset link → Opens callback.html in Edge ✅
  6. Click PasteCraft icon → Set your new password 🎉
🔍 Troubleshooting: If you still see an error, make sure you clicked "Save" in Supabase after adding all URLs, then reload the PasteCraft extension in Edge.
