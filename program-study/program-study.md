# Program Study Archive

After code implementation, before git commit:

1. Determine status: SUCCESS ✅ / PARTIAL ⚠️ / FAILURE ❌
2. Log to matching file:
   - SUCCESS → `success/SuccessLog.md`
   - PARTIAL → `partial/PartialLog.md`
   - FAILURE → `failure/FailureLog.md`

Log format: Date, feature, commit SHA, files, what worked/failed
