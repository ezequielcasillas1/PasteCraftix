# PasteCraft — Edge Store Listing Copy

## Short description (≤132 chars)
Smart clipboard manager for Edge with search, categories, Quick View, and Premium AI tools + cloud sync.

## Full description
PasteCraft helps you save, organize, and reuse everything you copy—so you never lose important snippets again.

### Core features (FREE)
- Clipboard history saved locally on your device
- Fast search across your saved clips
- Categories/folders to organize clips
- Notes + Albums: create multiple notes and group them into albums for organization
- One-click copy/paste actions and bulk management
- Quick View widget + right-click context menu access
- Productivity helpers: Deduplicate + Sort A→Z + clip-joining formats (comma/newline/space/custom)
- Clean UI with settings and customization

### Premium subscription unlocks
- Cloud sync to your PasteCraft account (access your clips across devices)
- AI tools:
  - Text Breakdown (explain content at different levels)
  - Smart Summary (summarize text or ask questions)
  - AI Image generation (create avatars/images from prompts or your uploaded photo)

### Free vs Premium
- **FREE:** Unlimited local clips + organization + search + Quick View
- **PREMIUM:** Cloud sync + AI tools
