# PasteCraft — Edge Store Listing Copy

## Short description (≤132 chars)
Smart clipboard manager with search, categories, Quick View, and AI. Break down text, summarize notes, and organize research clips as a study tool.

## Full description
PasteCraft helps you save, organize, and reuse everything you copy—so you never lose important snippets again. Freemium model: start free, upgrade to Basic (cloud sync) or Enhanced (AI tools). Use clipboard managing as an effective learning style: break down complex text, summarize research, and organize study materials in one place.

### Core features (FREE)
- Clipboard history saved locally on your device
- Fast search across your saved clips
- Categories/folders to organize clips
- Notes + Albums: create multiple notes and group them into albums for organization
- One-click copy/paste actions and bulk management
- Quick View widget + right-click context menu access
- Productivity helpers: Deduplicate + Sort A→Z + clip-joining formats (comma/newline/space/custom)
- 20+ markup formats (Markdown, LaTeX, code, MediaWiki, JIRA, etc.) + 190+ programming languages
- Clean UI with settings and customization

### Freemium model (subscription tiers)
- **Freemium (free)** — Unlimited local clips, search, categories, Notes + Albums, Quick View, markup support. Try before you upgrade.
- **Basic** — Everything Freemium + cloud sync + database storage (access clips across devices).
- **Enhanced** — Everything Basic + full AI access: Text Breakdown, Smart Summary, AI Image generation, Magic Wand, AI History, AI hints.

### Study tool use
- Break down complex text — Copy lecture notes or articles; get explanations at any level
- Summarize research — Paste long articles; generate summaries and ask follow-up questions
- Organize study materials — Use categories and notes to group clips by topic, course, or project
- Code snippets — Save and search code with syntax highlighting; join clips for study guides

### Innovative UI widgets
- **Highlight & drag** — Select text on any page and drag it into the Quick View box to save instantly—no copy needed
- **Screenpage widget view** — Currently in use; improved widget experience coming in future releases
- One-click copy/paste, right-click context menu, and floating Quick View for fast access
