## 🎨 Recraft AI Prompts

### 1. Main Logo/Icon (128x128 and 300x300)

**Prompt:**
```
Create a modern, professional app icon for "PasteCraft", a smart clipboard manager extension. 
The icon should feature:
- A stylized clipboard or document with a subtle sparkle/AI glow effect
- Incorporate copy-paste symbolism (stacked layers, clipboard, or document sheets)
- Color scheme: deep blue (#1e40af) to bright cyan (#06b6d4) gradient with purple (#8b5cf6) accent
- Clean, minimalist design that works at small sizes
- Slight 3D depth or isometric perspective
- Modern tech aesthetic with rounded corners
- Icon should be square with transparent or subtle background
Style: flat design with subtle gradients, tech-forward, professional
Size: 1024x1024 (will be scaled down)
```

**Export Settings:**
- Format: PNG
- Background: Transparent or solid color
- Resolution: 1024x1024 (then scale to 300x300, 128x128, 48x48, 32x32, 16x16)

## 📸 Screenshot Capture Guide

For the 5 required screenshots, you'll need to:

1. **Install PasteCraft in Edge** (developer mode)
2. **Open each key interface:**
   - Main popup (click extension icon)
   - Quick View widget (enable in settings)
   - Categories page (navigate to categories)
   - AI features page (show AI Lab/Images)
   - Search page (with search results)

3. **Capture Screenshots:**
   - Use Windows Snipping Tool or Snip & Sketch (Win + Shift + S)
   - Capture at 1280x800 or scale to 640x400
   - Include browser chrome for context
   - Ensure UI looks clean and professional
   - Show actual data (not empty states)

4. **Edit Screenshots:**
   - Add subtle drop shadows
   - Crop to consistent dimensions
   - Highlight key features with annotations (optional)
   - Ensure text is readable

## 🎨 Recraft AI Workflow

### Step 1: Generate Main Logo
1. Open Recraft AI (recraft.ai)
2. Choose "Icon" or "Illustration" project type
3. Paste the Main Logo prompt
4. Generate multiple variations
5. Select best version
6. Export as 1024x1024 PNG with transparent background
7. Scale down to required sizes: 300x300, 128x128, 48x48, 32x32, 16x16

### Step 2: Generate Promotional Tiles
1. Create new "Banner" or "Marketing" project
2. Use Marquee Tile prompt (1400x560)
3. Generate and refine
4. Export as PNG
5. Repeat for Small Tile (440x280)

### Step 3: Generate Feature Icons
1. Create new "Icon Set" project
2. Use Feature Icon Set prompt
3. Generate all 6 icons in one batch
4. Export each as separate 256x256 PNG with transparency

### Step 4: Create Screenshot Template
1. Use Browser Mockup prompt
2. Generate template
3. Export as 1280x800 PNG
4. Use as base layer in image editor
