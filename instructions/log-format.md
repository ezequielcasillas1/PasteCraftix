# Log Entry Format

When writing entries to any log/MD file:

**Make it:**
- Simple (clear language)
- Short (3-5 lines max)
- Detailed (include key info: date, files, what happened, why)

**Format:**
```
### [Date] - [Feature]
**Status:** [SUCCESS/PARTIAL/FAILURE]
**Files:** [file1.js, file2.js]
**Result:** [What worked/failed and why]
```

No verbose explanations. Just essential facts.
