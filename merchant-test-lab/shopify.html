Shopify product editor (mock)

Product tags + SEO meta fields

Course note: Shopify has product tags and SEO meta — no dedicated “materials” field like Etsy. Fabric content often goes in description or metafields.

Preset: Shopify — practical limit 250 tags × 255 chars (10 slots shown)

Product tags

Tags organize products in Shopify admin and some themes — loose limits (255 chars). Real Shopify uses one comma field; this mock uses separate inputs for Tag Queue testing.

Search engine listing (SEO)

SEO title and meta description control how the product appears in Google — separate from product tags and not visible as chips on the product page.
