Field glossary

Tags / keywords
Search terms buyers use to find listings. Strict count and character limits per platform (e.g. Etsy 13×20).
Materials
What the product is made of — fibers, metals, components. Etsy uses separate chips (not tags). eBay may use a “Material” item specific; most POD platforms have no materials field.
Title & description
Shopper-facing copy. Merchant deprioritizes these (Advanced) — don’t keyword-stuff.
Buyer instructions
Checkout personalization prompt. Primary Snippets paste target on Etsy.
Alt text
Per-image accessibility and SEO descriptions. Optional on Etsy.
Bullets (Amazon)
Visible selling points with character limits — not backend keywords.
Item specifics (eBay)
Category key-value pairs (Brand, Size, Material) — different from tag grids.
Hashtags (social)
Instagram/Pinterest discovery tags — not listing tags or materials.
Variants / SKU
Color, size, and inventory rows — grid paste targets (Printify mock).

Global checklist

  • Strip — Merchant badge + Pulse visible; page layout not broken
  • Listing Dock — tags-first UI, preview chips, count matches preset
  • Spot — stage comma tags or listing pack (tags: block)
  • Tag Queue — toggle on, focus tag input, next tag pastes
  • Materials — Etsy mock: queue into material inputs
  • Snippets — insert into buyer-instructions textarea
  • Seal & Ship — confirm clears staging; Pulse empty
  • Platform preset — dock Options popover limits match page preset
