Merchant Test Lab — mini course

Five-step path to validate Merchant before live seller dashboards.

  1. Load unpacked extension → reload after code changes
  2. Open Etsy mock first — full field set (tags + materials + snippets)
  3. Run each page’s green Test with PasteCraft Merchant checklist
  4. Switch dock Options preset per platform — limits must match mock meta line

Strip glossary

Listing Dock
Ephemeral staging — tags, materials, title/description. Save updates Pulse.
Pulse
Strip indicator — empty = no staging; live = dock has content.
Spot
Select page text → click Spot → stages into dock.
Image → Text
Drag a region → extracts text (DOM / alt / data-ocr-text) → dock tags.
Spot & Image → Text dock to
Second strip row — pick which dock field Spot and Image → Text send captured content into.
Tag Queue
Paste-next mode — focus tag input, Ctrl+V inserts next tag.
Material Queue
Paste-next mode — focus material input, Ctrl+V inserts next material.
Materials
Etsy-only — one fiber per chip input; stage comma list in dock Advanced.
Snippets
Reusable boilerplate — inserts into focused textarea.
Options
Dock preset popover — Etsy, Amazon, Custom limits.
