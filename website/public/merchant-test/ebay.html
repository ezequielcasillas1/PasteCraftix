eBay mock: eBay listings use category-defined item specifics (name → value pairs) instead of tag grids. Merchant helps paste short values into the value column — e.g. Material → Cotton — without confusing specifics with Etsy tags or materials chips.

Item specifics (name → value)

Each row is a filter buyers use — Brand, Size, Material, etc. Names come from eBay’s category; values are short (65 chars). Different from listing tags.

Test with PasteCraft Merchant

  1. Reload extension; open this page — confirm Merchant strip.
  2. Listing Dock → stage values for specifics (Brand, Material, Size) → Save → Pulse live.
  3. Spot → select a value placeholder (e.g. “Cotton”) → stages to dock.
  4. Tag Queue ON → focus value column (right input) → Ctrl+V pastes next value (65 char max).
  5. Leave name column (left) typed manually — eBay supplies category-specific names.
  6. Dock Copy tags / Paste next tag — queue through multiple value fields.
  7. Dock Options → eBay preset (12×65) → validate value length chips.
