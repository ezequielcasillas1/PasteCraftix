Etsy listing editor (mock)

13×20 tags, materials, buyer instructions, optional alt text — Phase 7 adapter target

Etsy mock: This page mimics Etsy’s listing editor — the marketplace where sellers paste into many small fields (13 tag slots, material chips, personalization notes). Merchant targets Etsy because strict limits and one-value-per-box inputs make comma-list paste fail. Learn each field here, then verify Tag Queue, Materials, and Snippets before editing a live listing.

Preset: Etsy — max 13 tags × 20 chars

Title & description (Advanced / collapsed)

Title and description are shopper-facing copy. Merchant treats these as Advanced — focus Tag Queue and Materials first; don’t keyword-stuff the big boxes.

Tags (13 slots × 20 chars)

Tags are Etsy search keywords — strict limit of 13 tags, 20 characters each. They help buyers find you; they are not materials or hashtags.

Materials

Materials answer “what is this made of?” — fibers, metals, wood types, etc. Etsy shows them as chips and uses them in buyer filters. Separate from tags; up to 13 on Etsy (5 slots here).

Etsy pattern: one material per input/chip — not a comma textarea. Example: cotton, linen, sterling silver each get their own slot.

Buyer instructions / personalization

Optional note shown at checkout — ask for names, colors, or care info. Primary Snippets paste target in Merchant.

Image alt text (10 slots — optional SEO pack)

Alt text describes each photo for accessibility and image search. Optional but helpful — one line per listing image.

Test with PasteCraft Merchant

  1. Reload extension (chrome://extensions → Reload); open this page.
  2. Confirm Merchant strip at top — Pulse empty, Listing Dock button visible.
  3. Listing Dock → stage tags, materials, and buyer-instruction text → Save → Pulse shows live staging.
  4. Spot → select tag placeholder text on page → selection stages to dock.
  5. Tag Queue ON → focus tag slot 1 → Ctrl+V pastes next tag; advance through all 13 slots.
  6. Materials → dock Copy materials or queue into each material input (one fiber per slot).
  7. Snippets → focus buyer-instructions textarea → Snippets → insert preset.
  8. In dock: Copy tags and Paste next tag — verify clipboard + queue advance.
  9. Seal & Ship → confirm → staging purged, Pulse empty.
  10. Dock Options → switch preset (e.g. Printify) → return to Etsy → re-validate 13×20 limits.
